## 🌍 PetLife
Bem-vindo ao PetLife, um site fictício de uma clínica veterinária, petshop e farmácia desenvolvido como projeto acadêmico para praticar habilidades de desenvolvimento front-end.

🔗 Acesse o site ao vivo: https://pet-life-dun.vercel.app/

## 💡 Visão Geral
O PetLife é um portal fictício que oferece serviços de clínica veterinária, petshop e farmácia, com foco no cuidado completo de animais de estimação. O site apresenta informações sobre consultas, produtos, serviços e contatos de forma simples, moderna e responsiva. O projeto tem como objetivo praticar boas práticas de desenvolvimento web.

## Objetivos do Projeto:
-Consolidar conhecimentos em HTML5, CSS3/SCSS e JavaScript.

-Criar um site responsivo e visualmente atraente.

-Explorar deploy com Vercel.

## 🧰 Tecnologias Utilizadas

- HTML5             # Estrutura do site
- CSS3/SCSS         # Estilização e design responsivo
- JavaScript        # Interatividade no site
- Vercel            # Hospedagem e deploy

## 📁 Estrutura do Projeto
PetLife/
  - assets/
    - imgs/            # Imagens do site
    - scripts/         # Arquivos JavaScript
    - styles/          # Arquivos CSS/SCSS
  - index.html         # Página principal
  - README.md          # Documentação do projeto

  
## ⚙️ Como Rodar o Projeto Localmente
Siga os passos abaixo para executar o projeto em sua máquina:

-Clone o repositório:   
   git clone https://github.com/Evandro-bz-Junior/PetLife.git
-Acesse a pasta do projeto:   
   cd PetLife   
-Abra o site no navegador:   
   Método rápido: Clique duas vezes no arquivo index.html para abri-lo diretamente no navegador.   
   Método recomendado: Use a extensão Live Server no VSCode para rodar o site localmente com recarregamento automático.
